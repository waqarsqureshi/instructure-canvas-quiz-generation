Compatibility and privacy

    A simpler way to author quizzes

    1. Name the bank. Add a question and choose its type.
    2. Write the question. Fill in answers and mark the correct choices. Everything is entered through forms, not JSON or Markdown.
    3. Build your bank. Duplicate questions, reorder them, and preview the student-facing text.
    4. Save project. Save the downloaded JSON in local-json. It contains answers and instructor notes and can be reopened here.
    5. Export Canvas ZIP. Fix validation errors, read the compatibility notes and save the ZIP in export.
    6. Test in Canvas. Create an empty, unpublished New Quiz, open its Build screen, and use its QTI import option. Check all question types and scoring before publishing. For Classic, use Settings → Import Course Content → QTI .zip file.

    Where to save and open files

    • local-json: your editable .quiz.json projects and the supplied practice example. Use Open project to select a JSON file from this folder.
    • export: the .zip packages you import into Canvas. ZIPs cannot be reopened as editable projects in this editor.

    These folders are beside this HTML file in the supplied package. In your browser's download settings, enable Ask where to save each file before downloading (or the equivalent option), then choose the appropriate folder when saving. If a download goes straight to Downloads, move it into the appropriate folder afterwards.

    The editor cannot automatically choose these folders or write beside the HTML file. Keep both folders private: JSON contains solutions and ZIP contains grading keys. Load example still works from the single HTML file without either folder.

    What is a stimulus?

    A stimulus is shared information used by several questions: a passage, scenario, matrix or set of given values. It is not a question, has no answer box and earns no marks. Keep solutions in private instructor notes, not in the stimulus.

    Example: “A stereo rig has f = 1000 px and B = 0.2 m” is the stimulus. “Find depth at disparity 40 px” and “Find depth at disparity 25 px” are two separate numerical questions linked to that same stimulus.

    1. Add a Shared stimulus, name it and enter the shared givens.
    2. Use Add linked question on that entry, or select it in an existing question's Shared stimulus (optional) dropdown.
    3. Check Student preview: the givens appear above the question.

    Try Load example and select Q13 — Shared stereo rig. This instructor example contains all 20 practice questions and their worked notes: 76 scored items (43 numerical, 33 essay), 12 shared stimuli, and 180 points. Save your current project before replacing it.

    Important limits

    New Quizzes export uses portable QTI 2.1, not a certified native Canvas exporter. Categorisation uses many-to-one matching. Stimulus text is repeated in linked questions. Formula samples become separate numerical questions. Ordering and hotspots require import testing. The export screen explains these transformations before download.

    Prompts use plain text and line breaks. LaTeX and HTML are not rendered. Images are supported for hotspots (local PNG/JPEG, up to 5 MB). Formulas allow variables, numbers, parentheses and + − * / ^. No scripts or functions are evaluated.

    There are no network requests. Browser drafts may be unavailable, cleared, or associated with this file location. Save project is your backup. Do not share source projects or ZIP answer keys with students.
